# Картинки для раздела «Еда и напитки»

Чтобы отображались картинки продуктов на странице бронирования, положите в эту папку файлы с **точными** именами:

| Имя файла        | Для продукта              |
|------------------|---------------------------|
| `cola-05.jpg`    | Кока-Кола 0.5л            |
| `popcorn-caramel.jpg` | Попкорн карамельный |
| `popcorn-big.jpg`     | Попкорн (большой)    |
| `water.jpg`          | Минеральная вода     |
| `nachos.jpg`          | Начос с сыром        |
| `hotdog.jpg`          | Хот-дог классический |
| `icecream.jpg`        | Мороженое пломбир    |
| `combo-premium.jpg`   | Комбо «Премиум»      |

**Как получить картинки:** откройте ссылку в браузере → правая кнопка мыши по изображению → «Сохранить изображение как…» → сохраните в эту папку с именем из таблицы.
